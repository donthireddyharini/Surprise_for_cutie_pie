# Background Images

## Instructions

1. Save the Keerthi background image as `keerthi-bg.jpg` in this folder
2. The image will be used as the background for the hero landing page
3. Recommended image properties:
   - Format: JPG or PNG
   - Min Width: 1920px
   - Min Height: 1080px
   - File size: Optimized for web (< 500KB recommended)
   - The image will be set to `background-attachment: fixed` for a parallax effect
   - A semi-transparent dark overlay (40% opacity) is applied for text readability

## Image Usage

The image is referenced in `src/components/birthday/HeroLanding.tsx` as:
```
backgroundImage: "url('/images/keerthi-bg.jpg')"
```

Simply save your image to this location and refresh the page to see the changes!
